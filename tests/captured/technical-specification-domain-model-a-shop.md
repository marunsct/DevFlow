## Domain Model
- User { id: UUID v7, email: string (unique, lowercase, 3-254 chars), passwordHash: string (bcrypt, 60 chars), role: 'admin' | 'vendor' | 'customer' | 'support', twoFactorSecret: string | null, locale: string (default 'en-US', ISO 639-1 with optional country code), preferredCurrency: string (default 'USD', ISO 4217), createdAt: DateTime, updatedAt: DateTime } — platform user accounts. Role determines access to pages and API endpoints.
- VendorProfile { id: UUID v7, userId: UUID (FK → User.id), businessName: string (min 1 char, max 200 chars), description: string (max 2000 chars), status: 'pending' | 'approved' | 'rejected', createdAt: DateTime, updatedAt: DateTime } — vendor store metadata. Status='approved' required before the vendor can create products.
- Product { id: UUID v7, vendorId: UUID (FK → VendorProfile.id), name: string (min 1 char, max 200 chars), description: string (max 5000 chars), price: Decimal(10,2) (non-negative, max 99999999.99), stock: number (integer ≥ 0), category: string (min 1 char, max 100 chars), images: string[] (array of URLs, max 5 entries), slug: string (unique, lowercase, URL-safe), createdAt: DateTime, updatedAt: DateTime } — catalog items. Indexed in Elasticsearch for search.
- Order { id: UUID v7, customerId: UUID (FK → User.id), status: 'processing' | 'shipped' | 'delivered' | 'cancelled', totalAmount: Decimal(10,2) (non-negative, includes subtotal + taxAmount + shippingAmount - discount), taxAmount: Decimal(10,2) (non-negative, calculated at checkout), shippingAmount: Decimal(10,2) (non-negative, calculated at checkout), shippingAddress: string (snapshot at checkout, max 500 chars), createdAt: DateTime, updatedAt: DateTime } — customer purchase record. Address is a text snapshot per DB-4.
- OrderItem { id: UUID v7, orderId: UUID (FK → Order.id), productId: UUID (FK → Product.id), quantity: number (integer ≥ 1), priceAtPurchase: Decimal(10,2) (snapshot at order time) } — line item within an order. Price snapshot ensures historical accuracy.
- CartItem { id: UUID v7, userId: UUID (FK → User.id), productId: UUID (FK → Product.id), quantity: number (integer ≥ 1) } — shopping cart entry. Composite unique constraint on (userId, productId); upsert logic handles quantity updates.
- Review { id: UUID v7, productId: UUID (FK → Product.id), userId: UUID (FK → User.id), rating: number (integer 1–5), comment: string (max 2000 chars), status: 'pending' | 'approved' | 'rejected', createdAt: DateTime } — customer review. Composite unique constraint on (productId, userId); existing review is updated instead of creating a new row.
- Payment { id: UUID v7, orderId: UUID (FK → Order.id), gateway: 'stripe' | 'paypal', amount: Decimal(10,2) (non-negative), gatewayTransactionId: string (unique, max 200 chars), status: 'pending' | 'completed' | 'failed' | 'refunded', createdAt: DateTime } — payment record. Unique constraint on gatewayTransactionId for idempotent webhook handling.
- Coupon { id: UUID v7, code: string (unique, max 50 chars, uppercase alphanumeric + hyphens), type: 'percentage' | 'fixed', value: Decimal(10,2) (non-negative), expiresAt: DateTime (must be in the future when active), isActive: boolean } — discount rules applied at checkout.
- WishlistItem { id: UUID v7, userId: UUID (FK → User.id), productId: UUID (FK → Product.id), addedAt: DateTime } — user-saved product for later. Composite unique constraint on (userId, productId) to prevent duplicates.
