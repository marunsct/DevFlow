- PUT /notes/{id} -> 200 + {"id": <integer>, "title": <string>, "body": <string>} or 404 + {"error": "<message>"} or 422 + {"error": "<message>"}: Replaces both title and body of an existing note. Requires JSON body with both "title" and "body" fields present. Validates title is non-empty (rejects with 422 if missing or empty). Rejects malformed JSON with 400. Returns the updated note on success, or 404 if no note exists with that id.
